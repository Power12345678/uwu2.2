# uwu 小手机：跨设备 Memory Palace 文件同步

手机上的 GitHub Pages 不能直接访问家里电脑的 `127.0.0.1`。现在推荐使用一个文件完成同步：

1. 手机上打开 uwu，进入目标私聊的 **CoreMemory / 记忆** 页面，点击 **导出同步包**。
2. 把下载的 `uwu_memory_sync_*.json` 传到电脑（微信文件传输、网盘、数据线都可以）。
3. 电脑上打开新版机器人的配置器，进入 **Memory Palace → 导入与迁移**，选择这个文件，点击 **一键导入 uwu 同步包**。

反向同步也使用同一个文件：在电脑配置器的同一页点击 **导出到 uwu 同步包**，把下载的 JSON 传回手机，在 uwu 的 CoreMemory / 记忆页面点击 **导入同步包**。它会合并 Bot 的完整原文、连续性摘要和短期上下文。

同步包包含：

- uwu 完整聊天历史中已经完成的 user→assistant 轮次；
- uwu 当前的连续性摘要。

电脑端会把完整原文写入 Memory Palace 的 `memory_messages`，交给 Palace 自己按正常水位线处理；不会把 uwu 的轮次游标强行改成已整理。连续性摘要单独按时间戳和正文去重后合并。同步包中同时有原文时，同一批摘要不会再次作为外部记忆重复提取。

重复导入同一个文件不会重复新增原文。手机上的历史消息被编辑后再次导入，会更新对应原文并触发相关旧记忆重新整理。导入失败可以重新选择同一文件；已写入的内容会去重。

旧的“同步到本机 bot”桥接代码仍为兼容保留，但不再作为手机跨设备同步入口。它只适用于 uwu 和 bot 在同一台电脑、且 bot 监听本机回环地址的情况。

## iPhone 后台消息与提醒

已有的音乐/静音音频保活继续保留。它能提高切到其他 App 后网页继续工作的机会；iOS 仍可能暂停网页或网络请求，因此不保证任何状态下都能继续生成 AI 消息。网页被完全挂起后仍由服务器生成并推送，需要额外的常驻服务和 Web Push，目前未提供这项服务。

系统通知请在 iOS 16.4+ 使用：Safari 分享菜单 → 添加到主屏幕 → 从主屏幕打开 uwu → 魔法屋 → 系统级通知 → 申请权限并开启。收到通知后点击会跳到对应聊天；uwu 内其他页面出现的消息弹窗也可以点击跳转。

魔法屋的“消息提醒方式”可选跟随系统、完全静音或播放提示音。跟随系统时不额外播放网页提示音；iOS 是否震动、怎样震动由系统和通知权限决定，网页无法保证模拟微信的震动。

收到回复后若本地存储失败，请先保持页面打开并检查存储空间。回到前台会重试本地保存，不会为此重新调用 AI；强制关闭/刷新前尚未补写的数据仍可能丢失。
